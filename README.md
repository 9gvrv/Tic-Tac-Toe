# Tic Tac Toe

A simple Tic Tac Toe game built with **HTML, CSS, and JavaScript**.

## Features

* Two-player gameplay
* Win and draw detection
* Restart button
* Simple responsive UI

## Run

Just open `index.html` in your browser and start playing.

## Tech Stack

HTML • CSS • JavaScript
